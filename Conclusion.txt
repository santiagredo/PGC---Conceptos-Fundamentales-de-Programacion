PROYECTO FINAL: CONCEPTOS FUNDAMENTALES DE PROGRAMACIÓN
RESUMEN Y CONCLUSIONES

1. LO APRENDIDO DURANTE EL DESARROLLO DEL PROYECTO

A lo largo de estas 7 semanas de trabajo en el proyecto, logramos poner en práctica 
conceptos clave de la programación en Java que fortalecieron nuestra lógica y forma 
de programar:
- Aprendimos a manejar archivos de texto e E/S avanzadas en Java (Java NIO y I/O), 
  procesando archivos CSV delimitados por punto y coma y aplicando limpieza de marcas 
  invisibles de formato (BOM de UTF-8).
- Implementamos **serialización de objetos** (Serializable, ObjectOutputStream y 
  `ObjectInputStream`) para crear respaldos binarios (.dat) eficientes de los catalogos 
  y acumulados de productos y vendedores.
- Usamos estructuras de datos como Map (HashMap) y `List` (`ArrayList) para asociar 
  e indexar información rápidamente, acumulando ventas provenientes de múltiples 
  archivos por vendedor y ordenando reportes con expresiones Lambda y `Comparators`.
- Diseñamos un programa modular y robusto con control de errores en bloques `try-catch`, 
  logrando que el sistema ignore líneas corruptas o datos incoherentes sin interrumpir 
  la ejecución.

2. POSIBLES APLICACIONES EN LA VIDA PROFESIONAL

Todo lo aprendido durante estas semanas tiene una aplicación muy directa en el mundo 
laboral:
- Automatización de procesos de integración y transformación de datos (ETL) para 
  consolidar información contable o de ventas proveniente de múltiples fuentes.
- Creación de mecanismos de **persistencia de datos de alto rendimiento** mediante 
  serialización binaria para sistemas en producción.
- Desarrollo de software backend capaz de procesar volúmenes de datos de forma 
  autónoma, segura y con tolerancia a fallos.

3. DIFICULTADES PRESENTADAS DURANTE EL DESARROLLO DEL PROYECTO

Durante estas semanas nos enfrentamos a varios retos que nos sirvieron como aprendizaje:
- Manejar la compatibilidad y lectura limpia de archivos CSV creados en Windows/Excel 
  debido a caracteres invisibles de codificación (BOM de UTF-8).
- Estructurar la lógica para permitir que un mismo vendedor acumule sus ventas desde 
  varios archivos de texto independientes (`ventas_*.txt`).
- Sincronizar y gestionar el control de versiones en equipo mediante Git y GitHub, 
  resolviendo conflictos de ramas.
